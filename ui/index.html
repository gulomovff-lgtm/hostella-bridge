  • Только защищённый канал. Все адреса — HTTPS, TLS не ниже 1.2; при ошибке сертификата соединение обрывается, а не продолжается.
  • Куда ходит мост: …. Других адресов, кроме портала e-mehmon, нет.
  • Паспортные данные — только в памяти. Задачи не пишутся на диск, номера паспортов вырезаются из журнала.
  • Пароль портала и ключ моста хранятся под шифрованием Windows (DPAPI) этого пользователя.
  • Портал — в изолированной сессии филиала: уход с emehmon.uz и запросы разрешений заблокированы.
